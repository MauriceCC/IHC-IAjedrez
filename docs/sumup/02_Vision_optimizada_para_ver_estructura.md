# Cap. 2 — Nuestra visión está optimizada para ver estructura (Gestalt)

**Idea clave:** el ojo agrupa y completa automáticamente. Usa los principios Gestalt a tu favor y verifica que no creen relaciones no deseadas.

## Reglas de diseño por principio

| Principio | Regla | Aplicación en UI |
|---|---|---|
| **Proximidad** | Lo cercano se percibe como grupo. | Agrupa controles **solo con espacio**, sin cajas ni líneas. La etiqueta va **pegada a su control** y lejos de los demás. |
| **Similitud** | Lo parecido se percibe como grupo. | Mismo estilo = misma categoría (ej. correos no leídos en negrita). No hagas parecidos elementos que no están relacionados. |
| **Continuidad** | Elementos alineados se ven como una forma continua. | Sliders, alineaciones, logotipos. Alinea lo que debe leerse como un todo. |
| **Cierre** | El ojo completa figuras abiertas. | Pilas de objetos, iconos parcialmente visibles. |
| **Simetría** | Se interpreta la forma más simple y simétrica. | Presenta datos en **tablas** en vez de prosa. |
| **Figura/Fondo** | Se separa primer plano y fondo. | Fondos para dar contexto/marca; **superpone** pop-ups sobre el contenido en lugar de reemplazarlo (mantiene orientación). |
| **Destino común** | Lo que se mueve junto se percibe relacionado. | Animaciones de grupo, arrastre de selección múltiple. |

## Evitar

- **Caja de grupo alrededor de un solo elemento** o cajas innecesarias (ruido visual).
- Etiquetas equidistantes entre dos controles.
- Similitud o proximidad accidental que sugiera grupos inexistentes.

## Verificación

- Al terminar un diseño, **revísalo con los 7 principios uno por uno** buscando relaciones visuales no intencionadas.
