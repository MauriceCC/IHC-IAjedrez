# Cap. 9 — Reconocer es fácil; recordar es difícil

**Idea clave:** el cerebro es un motor de **reconocimiento** (rápido, sin búsqueda). **Recordar** sin estímulo perceptivo es lento y falla. Base de toda la GUI.

## Reglas de diseño

1. **"Ver y elegir" es mejor que "recordar y escribir".** Muestra las opciones; no obligues a recordarlas. (Excepción válida: cuando lo que hay que escribir es fácil de recordar, como palabras de búsqueda).
2. **Usa imágenes para comunicar funciones** (íconos, símbolos de error). Íconos buenos: **sugieren su significado, se distinguen entre sí y se usan siempre con el mismo significado**. Idealmente con texto.
3. **Usa miniaturas** para representar imágenes ya vistas: permiten ver más opciones a la vez.
4. **Cuanta más gente use una función, más visible debe ser.** Lo de uso experto/minoritario puede ir oculto (menú contextual, "Detalles", atajos).
5. **Da pistas de dónde está el usuario:** estilo visual común en todo el sitio, con variaciones sistemáticas por sección.
6. **No cambies sin necesidad elementos visuales prominentes** de una página (ej. carruseles automáticos): el usuario puede creer que cambió de página.
7. **Autenticación fácil de recordar:** contraseñas que se puedan recordar, preguntas de seguridad propias, pistas de contraseña, recuperación sencilla; biometría solo con protección estricta de datos.
